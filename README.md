# Savory Haven 🍽️

A responsive restaurant website built with HTML and CSS.

## About

Savory Haven is a restaurant landing page created to practice and demonstrate responsive web design using HTML and CSS.

## Features

- Responsive design for mobile, tablet, and desktop
- Restaurant menu section
- Customer testimonials
- Contact section
- Reservation form
- CSS animations and transitions
- CSS custom properties
- Flexbox layouts
- Media queries
- CSS keyframes

## Technologies Used

- HTML5
- CSS3

## What I Learned

This project helped me put my CSS knowledge into practice, especially with responsive layouts, Flexbox, media queries, animations, transitions, and CSS variables.
